# Controls

[← Back to README](../README.md)

Controllers, keyboard and mouse can be used at the same time. Controllers are read only while the game window
has focus.

---

## DualSense, DualSense Edge and DualShock 4

PS5 and PS4 controllers work over **USB or Bluetooth** with no extra software (no DS4Windows or Steam Input
needed).

- Every button works as on the PS4.
- **Touch pad:** swipes and click.
- **Motion sensors:** used in the "Don't move" moments; hold the controller still.
- Tested with a DualSense. DualSense Edge and DualShock 4 use the same code paths but have not been tested
  separately.
- **Not supported yet:** vibration and the light bar on these controllers.

---

## Xbox-style controllers (XInput)

Includes Xbox controllers and virtual pads made by DS4Windows or Steam Input. **Vibration works.**

| Xbox | PS4 |
| --- | --- |
| A | Cross |
| B | Circle |
| X | Square |
| Y | Triangle |
| LB / RB | L1 / R1 |
| LT / RT | L2 / R2 |
| Left / right stick | Left / right stick |
| Stick clicks | L3 / R3 |
| D-pad | D-pad |
| Menu (Start) | Options |
| View (Back) | Touch pad click |

XInput controllers have no touch pad and no motion sensors:

- Use the keyboard keys **F / G / R / V** for touch pad swipes.
- In "Don't move" moments the controller counts as held still.

## Keyboard

| PS4 | Key |
| --- | --- |
| Left stick | W A S D |
| Right stick (camera) | I J K L |
| Cross | Enter or Space |
| Circle | Esc or Backspace |
| Square | Q |
| Triangle | E |
| L1 / R1 | 1 / 3 |
| L2 / R2 | Z / C |
| D-pad | Arrow keys |
| Options | Tab |
| Touch pad click | T |
| Touch pad swipe left / right / up / down | F / G / R / V |
| L3 / R3 | Not available on the keyboard (use a controller) |

The keys cannot be remapped yet.

---

## Mouse

- **Touch pad finger:** hold the left mouse button inside the window and drag.
- **Mouse aiming:** press **M** to turn it on or off. While it is on:

| Mouse | PS4 |
| --- | --- |
| Movement | Right stick (camera / aim) |
| Left button | R2 (shoot) |
| Right button | L2 (aim) |

---

## Skipping movies

The intro logos, the "Previously on Until Dawn" recaps, the butterfly-effect tutorial, the movie that opens the
prologue and the Chapter 1 bus ride can be skipped:

1. Press any button. A **Skip** prompt appears in the bottom-right corner.
2. Press **Cross** (Enter / Space) while it is shown.

When a recap is skipped, the rest of that recap is skipped with it.
