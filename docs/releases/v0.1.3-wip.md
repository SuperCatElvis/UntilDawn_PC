## What's new in 0.1.3

### Fixed: false "missing files" message with long folder paths
WIP 0.1.2 used Windows file functions limited to 260 characters. With a long folder path (for example the ZIP
extracted into a folder of the same name), the game's longest file names went over that limit and were reported
as missing although they were there. Long paths now work. Verified with the folder that reported 40 missing
files in 0.1.2.

### Fixed: AMD graphics (confirmed)
On an AMD Radeon RX 9070 XT, WIP 0.1.2 showed noisy textures, black blocks, trees and bushes partly missing, and
lighting that ended in square steps around characters and trees. With test builds and frame captures from that
PC, replayed and compared on the development PC, the causes were found and fixed in the shader translation:

- **Helper pixels:** the translated pixel shaders emulated a PS4 detail everywhere (the extra "helper" pixels
  used for texture detail started switched off). On the AMD driver this lost whole 8×8 blocks of alpha-tested
  foliage, which in turn put the per-tile lighting out of step. The emulation is now kept only in the shaders that
  need it (95 of about 3,900); elsewhere the helper pixels run normally.
- **2×2 pixel groups** stay together when pixel shaders branch before texture sampling (non-NVIDIA GPUs).
- **A compute shader** that needed 12 bytes more than the 32 KB of shared memory on such GPUs now fits.
- Shaders that need 32-lane waves now request them on GPUs that support several wave sizes.

These are changes to the translation itself, not AMD-only switches. On NVIDIA only a few outline pixels change.
**Confirmed:** on the same RX 9070 XT, 0.1.3 now looks the same as on NVIDIA (including the same remaining known
issues). Reports from other AMD GPUs are still very welcome.

### Also
- The compatibility tester (`compat\run_compat.bat`) is updated with the same changes.
- Documentation: a known issue for game files that were skipped while copying (one long file name "missing"
  although the game was copied) with a `robocopy` fix.
- More tested hardware in the README (NVIDIA RTX 3060 Ti, 3080, 3090, 5070 and 5070 Laptop GPU; AMD Ryzen 5700G,
  7500F, 5700X, 5800X and 9600X; AMD Radeon RX 9070 XT).

## Updating from 0.1.2

Copy the new `UntilDawn.exe`, `compat\ud_compat.exe` and the text files into your 0.1.2 folder. **Do not
overwrite** `Config\settings.ini`, `savedata\` or `Game\` (your settings, saves and game). Or extract 0.1.3 to a
new folder and copy your `settings.ini`, `savedata` and game files over. Shaders are translated anew, so the
first-run stutters (10–20 second pauses while new areas load) return once.

## Getting started

1. Download **`UntilDawn_WIP_0.1.3.zip`** below and extract it to a folder you can write to.
2. Put your game files in the `Game` folder (so that `Game\eboot.bin` exists), or set `game_dir` in
   `Config\settings.ini`.
3. Start **`UntilDawn.exe`**.

Full instructions: [Installation guide](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/INSTALLATION.md)
· [Controls](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/CONTROLS.md)

## Requirements

- Windows 10 or 11, 64-bit
- CPU with AVX, F16C, BMI1, LZCNT, POPCNT and MOVBE (Intel Haswell / AMD Ryzen or newer)
- 16 GB memory recommended
- GPU with a current Vulkan 1.3 driver (NVIDIA and AMD tested; Intel untested)

## Known issues (unchanged from 0.1.2)

- Occasional crashes (twice in a full play-through on the development PC; saves are kept)
- Characters occasionally deform for a frame or two
- Black mouths in some close-ups, a red flash in the Episodes menu, smeared end-credits text
- Frame-rate drops: some sections run well below 30 FPS. Performance is not addressed yet and will be improved
  in future releases
- No vibration or light bar on PlayStation controllers yet

Full list: [Known issues](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/KNOWN_ISSUES.md)
