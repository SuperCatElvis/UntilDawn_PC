v0.4.1 is a small hotfix for v0.4.0 aimed at PCs with little memory (for example laptops with 16 GB of RAM). The
program now detects when the graphics driver gives it only a small amount of system memory, uses a little less memory
in that case, and writes a clear warning to the log. It does **not** yet fix the crash some 16 GB PCs see when loading
demanding scenes (see Known Issues). On PCs with more memory nothing changes. Your settings are kept as they are.

> [!IMPORTANT]
> **No game files are included.** You still need your own legally obtained copy of Until Dawn (2015) for PS4,
> **CUSA02636**, with update **1.03** applied. The program checks your game files at every start.

> [!WARNING]
> This is still a **work-in-progress** release. Expect occasional crashes, graphical issues and stutters.

## Fixed

- No crash fixes in this version. The low-memory changes below reduce memory use slightly on small systems, but they
  do not fix the Chapter 6 / menu crash on some 16 GB PCs (see Known Issues).

## Improvements

- **Automatic low-memory mode.** At start-up the program asks the graphics driver how much system memory it may use
  (on drivers that don't report it, the installed RAM is used instead). When that is small, it uses a smaller upload
  buffer (128 MB instead of 512 MB) and keeps more video memory free. On PCs with plenty of memory this mode stays off
  and nothing changes.
- **LOW MEMORY warning.** In that case `Logs\UntilDawn.log` says so at start-up, with how much memory the game needs
  and a reminder to close other programs (web browser, game launchers, overlays, recording tools) before playing.
- **Memory details in the log every 10 seconds** while low-memory mode is on, to help with bug reports.
- Optimised Rendering (Fast Mode) and the GPU optimisations stay on by default on every PC, and your
  `Config\settings.ini` is not changed by this update.

## Performance

- Unchanged on PCs with enough memory.
- In low-memory mode performance can be somewhat lower: in our test with a simulated small memory budget, an average
  frame took about 17.1 ms instead of about 14.7 ms.

## Known Issues

- **Some PCs with 16 GB of RAM can crash when loading demanding scenes**, for example the Chapter 6 chair scene or a
  main menu that shows it (the game stops with a graphics "device lost" error). v0.4.1 does not fix this yet. v0.3.2 may
  work better on these PCs. A larger memory reduction is planned. Closing other programs before playing can help.
- All known issues of v0.4.0 still apply: the main-menu look-around is too fast at high frame rates, brief dark
  lighting at the start of some scenes, first-start shader preparation time depends on your CPU, occasional brief
  stutters when entering new areas, Optimised Rendering has mostly been tested on NVIDIA graphics cards, and the memory
  corruption behind most remaining crashes is not fixed yet.

## Updating from v0.4.0

Copy the new `UntilDawn.exe`, `compat\ud_compat.exe` and the text files into your v0.4.0 folder (`pipelines.udm` is
unchanged). **Do not overwrite** `Config\settings.ini`, `savedata\` or `Game\`. There are no new settings. As after
every update, the first start shows the "Preparing shaders" screen once more.
