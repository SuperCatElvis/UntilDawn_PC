# Until Dawn Native PC Recompilation – WIP 0.1.2

**Tag:** `v0.1.2-wip` · **Pre-release** · **Asset:** `UntilDawn_WIP_0.1.2.zip`

> [!WARNING]
> This is the **first public work-in-progress test release**. Expect bugs, crashes, graphical problems,
> stutters and hardware compatibility issues.

> [!IMPORTANT]
> **No game files are included.** You need a decrypted dump of the original PS4 Until Dawn (**CUSA02636**) with
> the **01.03** update, made from your own **legally obtained** copy of the game. This download does not contain
> the game.

## What this is

A native Windows version of the **original 2015 PS4 Until Dawn** (not the 2024 remake). The game's own x86-64
code runs directly on your CPU — **no console emulation**. This project replaces the PS4 system libraries and
draws the game with a custom Vulkan renderer that translates the game's GPU work and shaders on your PC.

## Highlights

- **Playable from start to finish:** the whole game has been played through on the development PC.
- **Controllers:** DualSense, DualSense Edge and DualShock 4 over USB or Bluetooth (touch pad and motion
  sensors included), Xbox-style controllers with vibration, and keyboard and mouse with mouse aiming.
- **"The Road Not Taken"** pre-order DLC works if you supply its folder.
- **Skippable intro logos and "Previously on" recaps.**
- Windowed / borderless modes, frame-rate limit (60 FPS default), on-disk shader cache.
- Startup checks for the game files, CPU and graphics card with plain-language messages.
- Included **hardware compatibility tester**.

## Getting started

1. Download **`UntilDawn_WIP_0.1.2.zip`** below and extract it to a folder you can write to.
2. Put your game files in the `Game` folder (so that `Game\eboot.bin` exists), or set `game_dir` in
   `Config\settings.ini`.
3. Start **`UntilDawn.exe`**.

Full instructions: [Installation guide](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/INSTALLATION.md)
· [Controls](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/CONTROLS.md)

**First play-through:** shaders are compiled for your graphics card as new areas load. The game can freeze for
**10–20 seconds** at a time, mostly in the first minutes. Wait for it; later runs are much smoother.

## Requirements

- Windows 10 or 11, 64-bit
- CPU with AVX, F16C, BMI1, LZCNT, POPCNT and MOVBE (Intel Haswell / AMD Ryzen or newer)
- 16 GB memory recommended
- GPU with a current Vulkan 1.3 driver (NVIDIA tested; AMD and Intel untested)

## Known issues

- Occasional crashes (twice in a full play-through on the development PC; saves are kept)
- Characters occasionally deform for a frame or two
- Black mouths in some close-ups, a red flash in the Episodes menu, smeared end-credits text
- Frame-rate drops: some sections run well below 30 FPS. Performance is not addressed in this test release and
  will be improved in future releases
- No vibration or light bar on PlayStation controllers yet
- **AMD and Intel graphics and AMD CPUs are untested**

Full list: [Known issues](https://github.com/SuperCatElvis/UntilDawn_PC/blob/main/docs/KNOWN_ISSUES.md)

## Help wanted: hardware testing

Only one PC (Intel + NVIDIA) has been tested. If you have an **AMD or Intel GPU**, or an **AMD CPU**, please run
`compat\run_compat.bat` and attach the resulting `compat_report.zip` to a
[compatibility report](https://github.com/SuperCatElvis/UntilDawn_PC/issues/new/choose) — even if everything
passes.

## Reporting bugs

Open an issue on [GitHub Issues](https://github.com/SuperCatElvis/UntilDawn_PC/issues) with what happened, where
in the game, a screenshot for graphical problems, `Logs\UntilDawn.log` (or `UntilDawn.previous.log` after a
restart) and `compat\compat_report.zip`.
