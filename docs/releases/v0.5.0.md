Until Dawn PC Recompilation — v0.5.0

Release date: (to be filled in on release)

v0.5.0 brings cleaner sound, more languages, a second supported PS4 edition, fixes for Dr Hill's book, the
motion-control drift and thin lines at high resolutions, fewer start-up problems and an optional automatic updater.

> [!IMPORTANT]
> **No game files are included.** You need your own legally obtained copy of Until Dawn (2015) for PS4 —
> **CUSA02636** or **CUSA00194** — with update **1.03** applied. The program checks your game files at every start.
> Other editions: see `COMPATIBILITY.txt`.

> [!WARNING]
> This is still a **work-in-progress** release. Expect occasional crashes, graphical issues and stutters.

## New

- **Language Importer** (`UDLanguageImporter.exe`, and `ud_langscan.exe` for the command line). Adds the languages of a
  second PS4 edition you own, once, into the `Languages` folder:
  - from CUSA00194: French, German, Italian (text and voices), Dutch, Turkish (text);
  - from CUSA02636: Spanish, Portuguese, Russian, Polish (text and voices), Danish, Finnish, Norwegian, Swedish (text).
  Languages already in your own game are recognised and not imported again. Other editions can be imported as
  experimental. No game files are included.
- **Easier language choice.** `Config\settings.ini` now lists all 20 languages of the game: name, short code, voices or
  text only, which editions contain it and whether it is verified. Write e.g. `language = french` or `language = fr`.
- **CUSA00194 (Europe 1) supported**, as well as CUSA02636. Its 01.03 program is identical to CUSA02636's except for
  signature and build data. Other editions are accepted only when their program file is the same original 01.03 program
  (experimental); anything else is refused with a clear explanation (`COMPATIBILITY.txt`).
  CUSA00359 (Americas) is accepted as experimental; its file list was contributed to the project repository
  (commit 8baf8a1). CUSA00194's empty `title-id.txt` is handled (the game would otherwise stop at start).
- **Automatic updater**, built into `UntilDawn.exe` and on by default (`update_check = 0` turns it off). At start it checks
  GitHub for a new release and asks before installing anything. It
  verifies the download (size and SHA-256) and can roll back an interrupted install. It only replaces program files:
  your `Game`, `savedata`, `Config`, `Languages`, `Cache` and `Logs` folders are never touched.
- **Depth of field setting** (`depth_of_field = 0` in `Config\settings.ini`, restart after changing): turns depth of
  field, bokeh and motion blur off. Default 1, as on the PS4.

## Fixed

- **Crackling and spikes in the sound**, mostly heard at 4K: the game's sound is now read when it is played, as on the
  PS4, and a limiter keeps loud moments from clipping.
- **Dr Hill's book** showed the wrong pages (for example the pistol / knife and rats / cockroaches pages).
- **DualShock 4 / DualSense motion-control drift** during "Don't Move" moments.
- **Thin bright lines** along edges at resolutions above 1080p (`rs_depth_max = auto`).
- **Start-up stop "TlsAlloc returned an index >= 64"** with overlays and some other programs
  ([issue #9](https://github.com/SuperCatElvis/UntilDawn_PC/issues/9)).
- A rare start-up stop when Windows had placed its own memory where the game needs it: the program now simply starts again.
- A rare crash from two threads changing the cloth simulation's list at once (Chapter 5).

## Improvements

- **Graphics cards under 12 GB:** textures are managed in smaller blocks and recently used ones are kept, so fewer
  textures are reloaded.
- **PCs with little memory:** about 1.5 GB less memory is handed to the graphics driver automatically when it is tight
  (`low_driver_memory = auto`). Measured to lower memory use; not yet confirmed to fix the crash some 16 GB PCs see.
- **Graphics cards with 8 GB or more:** more work is batched per frame (automatic).
- **Older processors** (Intel Sandy / Ivy Bridge, AMD FX): `cpu_compat = 1`, with a message that says when it is needed.
- The compatibility test (`ud_compat`) also lists other programs' Vulkan layers and free thread slots.
- Your `Config\settings.ini` is kept: new settings are added with their defaults and the language notes are updated;
  your own values stay.

## Performance

- Measured on the development PC (RTX 3090 Ti, Core i9-12900KF) against v0.4.1: the same or slightly better at 1080p,
  1440p and 4K in the prologue (1080p, 1440p, 4K) and the cave (1440p, 4K), alternated runs. Heavy scenes still run below 60 FPS on many PCs.

## New settings

`language`, `text_language`, `speech_language` (names or codes), `low_driver_memory` (auto), `rs_depth_max` (auto),
`depth_of_field`, `cpu_compat`, `update_check`, `audio_late_read`, `audio_limiter`, `gyro_calibration`,
`low_vram_textures`.

## Known issues

- Occasional crashes from memory that is overwritten (not fixed yet).
- Some 16 GB PCs may still crash in demanding scenes.
- A few bright frames after a camera cut in the Chapter 5 stranger scene.
- AMD graphics reports ([issue #15](https://github.com/SuperCatElvis/UntilDawn_PC/issues/15)) are still being investigated.
- Languages from the US, Asian and Japanese editions are experimental.

See `KNOWN_ISSUES.txt` for the full list.
