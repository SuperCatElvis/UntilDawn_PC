Until Dawn native PC port - known issues (WIP 0.1.4, 25 October 2026)
=====================================================================

This is a work-in-progress test build. What is known so far:

New in 0.1.4: the renderer thread
---------------------------------
  - The renderer now runs on its own thread, alongside the game (a large part of 0.1.4's speed-up). So far it
    has only been played on the developer's PC (NVIDIA RTX 3090 Ti, Intel Core i9-12900KF). If 0.1.4 crashes,
    freezes or stutters on your PC where 0.1.3 did not, set  renderer_thread = 0  in Config\settings.ini: the
    renderer then runs on the game's thread as in 0.1.3. Please report whether that helped.

Stability
---------
  - Occasional crashes. In a full play-through on the developer's PC (0.1.3) the game crashed twice and had to be
    restarted; saves were kept. The cause is being investigated: some of the game's memory is occasionally
    overwritten (characters' animation data, object tables). The program contains safeguards that catch most
    of these cases, but not all. 0.1.4 changes two things that may be involved; whether crashes became rarer
    still has to be confirmed.
  - Characters can briefly deform ("explode") for a frame or two - the same memory problem as above.
  - Collectibles: a totem has been seen to vanish, and a clue to reappear after it was picked up.

Graphics
--------
  - The inside of mouths can render black in some close-ups.
  - A red flash over the screen while moving through the Episodes menu.
  - The text at the start of the end credits is smeared vertically.
  - Totem visions: the video can play without the rest of the totem screen (its background and UI), e.g. when a
    totem is rewatched after it played correctly the first time; sometimes the whole UI disappears and only
    the character and the background remain.
  - In the second "stranger" shot of the prologue, fog and haze can disappear for a frame or two just after the
    stranger walks past.
  - The Skip prompt's "Skip" text shows as white boxes on the butterfly-effect tutorial and the movie that opens
    the prologue, and can in the later "Previously on Until Dawn" clips (the Cross button is right and skipping
    works). The game's own text in the same overlay movie is drawn in pieces then too: a renderer fault, being
    investigated.
  - The Cross (X) button and subtitles can occasionally look glitchy.
  - Small differences from the PS4 picture are possible elsewhere; please report anything that looks wrong.
  - Fixed in 0.1.4: hair that looked hazy or see-through (fog and light shafts behind characters were drawn
    over it).

Performance
-----------
  - Much better than in 0.1.3, but the frame rate still varies by scene. On the developer's PC (RTX 3090 Ti,
    Core i9-12900KF): light scenes often reach 60 fps, busy scenes about 35-45 fps, and the heaviest scenes
    measured (the prologue's "stranger" shots) about 21-25 fps (about 5 fps with 0.1.3). Slower PCs will see
    lower numbers. The 60 fps limit is a limit, not a guaranteed frame rate.
  - Shader compilation on the first play-through: stutters, and occasional freezes of 10-20 seconds, mostly in
    the first minutes of each new area (a fresh install froze for about 12 and 17 seconds in the prologue on the
    developer's PC). The game is not hung - wait for it. The shader cache (Cache\) removes most of these on
    later runs; a cache from 0.1.3 stays valid.

Hardware
--------
  - Full play-through (0.1.3): Intel Core i9-12900KF + NVIDIA GeForce RTX 3090 Ti (drivers 617.42 and 621.01),
    Windows 11, 64 GB. 0.1.4 has been played on the same PC.
  - Compatibility test passed (0.1.2 / 0.1.3): NVIDIA RTX 3060 Ti, 3080, 3090, 5070 and 5070 Laptop GPU,
    AMD Radeon RX 9070 XT, with Intel and AMD Ryzen CPUs.
  - AMD Radeon: 0.1.2 rendered badly on an RX 9070 XT (noisy textures, black blocks, missing foliage, stepped
    lighting). Fixed in 0.1.3 and confirmed on that card. 0.1.4 translates the shaders exactly as 0.1.3 does,
    but 0.1.4 itself has not been played on an AMD card yet - reports are welcome.
  - Intel Arc / integrated graphics are untested. Please run compat\run_compat.bat on these and send the report
    even if the game runs fine.
  - Game files reported "missing" although they are there: fixed since 0.1.3 for long folder paths. If one file
    is still missing, it usually was not copied: the copy (or unzip) of your game skipped it because the folder
    you copied FROM had a long path. Copy that file again, e.g. with robocopy, from a short folder.
  - Vibration and the light bar of DualSense / DualShock 4 controllers are not supported yet (Xbox controllers
    vibrate).

Game version
------------
  - Only CUSA02636 with the 01.03 update is supported. Other regions or versions are refused at start.
  - Online / PlayStation Network features are not available. Trophy unlocks are recorded locally (savedata\ and
    the log); there is no on-screen trophy notification.
